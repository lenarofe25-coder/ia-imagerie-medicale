# L’IA dans l’imagerie médicale

Présentation interactive qui défile toute seule : détection assistée de tumeurs, fiabilité et questions éthiques.

**Voir la présentation :** https://lenarofe25-coder.github.io/ia-imagerie-medicale/

Commandes : `Espace` pause · `←` `→` diapositive précédente / suivante · `F` plein écran · `M` son.
